# Input Stickman Video Data

This folder contains stickman figure images extracted from video, along with keypoint annotations and rendered skeleton visualizations.

## Folder Structure

```
input_stickman_video/
├── all_bw_images/             # Original B&W stickman images (original resolution)
├── all_bw_images_480p/        # Resized B&W images (480x640) - used for annotation
├── all_colored_images/        # Colored stickman images (original resolution)
├── skeleton_images/           # Rendered OpenPose-style color-coded skeletons
├── keypoint_annotations/      # Keypoint annotation data
│   ├── annotations.json
│   ├── annotations_manual_backup_v1.json
│   └── annotations_manual_backup_v2.json
└── README.md                  # This file
```

## Image Folders

### `all_bw_images/`
Original black & white stickman figure images at their native resolution.

### `all_bw_images_480p/`
Resized versions of the B&W images at 480x640 resolution. **This is the primary dataset used for keypoint annotation and training.**

- **509 images** total
- Named: `vid{N}_{frame}.jpg` (e.g., `vid1_1.jpg`, `vid1_2.jpg`, ...)
- Multiple video sources (vid1 through vid21)

### `all_colored_images/`
Colored versions of the stickman images at original resolution. Used as reference for skeleton rendering dimensions.

### `skeleton_images/`
**OpenPose-style color-coded skeleton visualizations** generated from the keypoint annotations.

- Generated by: `tools/render_openpose_skeleton.py`
- Format: PNG images on black background
- Named: `{original_name}_skeleton.png` (e.g., `vid1_1_skeleton.png`)
- Style: Matches ControlNet DWPose / controlnet_aux output
- Uses standard OpenPose 18-keypoint color scheme (rainbow gradient)

**To regenerate:**
```bash
python tools/render_openpose_skeleton.py
```

## Keypoint Annotations

### `keypoint_annotations/annotations.json`
The active annotations file containing keypoints for all 509 images.

**Format:**
```json
{
  "vid1_1.jpg": [
    [x, y, visibility],  // 0: nose
    [x, y, visibility],  // 1: neck
    [x, y, visibility],  // 2: right_shoulder
    [x, y, visibility],  // 3: right_elbow
    [x, y, visibility],  // 4: right_wrist
    [x, y, visibility],  // 5: left_shoulder
    [x, y, visibility],  // 6: left_elbow
    [x, y, visibility],  // 7: left_wrist
    [x, y, visibility],  // 8: right_hip
    [x, y, visibility],  // 9: right_knee
    [x, y, visibility],  // 10: right_ankle
    [x, y, visibility],  // 11: left_hip
    [x, y, visibility],  // 12: left_knee
    [x, y, visibility],  // 13: left_ankle
    [x, y, visibility],  // 14: right_eye
    [x, y, visibility],  // 15: left_eye
    [x, y, visibility],  // 16: right_ear
    [x, y, visibility]   // 17: left_ear
  ],
  ...
}
```

**Visibility values:**
- `0` = keypoint not visible / not annotated
- `2` = keypoint visible

**Keypoint format:** OpenPose 18-point body keypoints (no hands/face). Compatible with DWPose format.

### `annotations_manual_backup_v1.json`
Backup of ~80 manually annotated images (early checkpoint).

### `annotations_manual_backup_v2.json`
Backup of 126 manually annotated images (used to train the prediction model).

## OpenPose 18-Keypoint Skeleton

The skeleton connections used:
```
nose (0) ── neck (1)
              ├── right_shoulder (2) ── right_elbow (3) ── right_wrist (4)
              ├── left_shoulder (5) ── left_elbow (6) ── left_wrist (7)
              ├── right_hip (8) ── right_knee (9) ── right_ankle (10)
              └── left_hip (11) ── left_knee (12) ── left_ankle (13)

nose (0) ── right_eye (14) ── right_ear (16)
        └── left_eye (15) ── left_ear (17)
```

## Usage

### View/Edit Annotations
```bash
python tools/annotate_keypoints.py
```

### Render Skeleton Images
```bash
python tools/render_openpose_skeleton.py
```

### Train Keypoint Model
```bash
python tools/train_keypoint_v3.py
```

### Predict on Unannotated Images
```bash
python tools/predict_keypoints_v3.py
```

See `tools/README.md` for detailed documentation on the annotation workflow.
